# China at 60 — GitHub Pages-ready website

This folder is the complete static site. Open `index.html` locally to review it.

To publish on GitHub Pages, sign in to GitHub, create a repository, and upload `index.html`, `styles.css`, `app.js` and the `assets` folder to the repository root. Then open **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose your default branch and **/(root)**, and save. GitHub will display the public site URL on that page when deployment finishes.

The site is public when published on GitHub Pages. It contains no personal names, but it does describe a family birthday trip and travel-pacing considerations; review those details before uploading.

Itinerary and prices were researched on 17 September 2026. All 2027 prices are estimates, not reservations or date-specific quotes. Recheck sources, entry rules, accessibility and insurance before booking.
